# Ritm

Простая утилита для Windows 10/11 в один файл с графическим интерфейсом, которая очищает временные и мусорные файлы.

![platform](https://img.shields.io/badge/platform-Windows-blue)
![license](https://img.shields.io/badge/license-MIT-green)

🇬🇧 [Read in English](README.md)

## Что очищается

- `%TEMP%`, `%TMP%`, `C:\Windows\Temp`
- Кэш Центра обновления Windows (`SoftwareDistribution\Download`, `DeliveryOptimization`)
- Отчёты об ошибках (WER) и дампы сбоев (`CrashDumps`, `Minidump`, `MEMORY.DMP`)
- Кэш шейдеров DirectX (`D3DSCache`)
- Кэш миниатюр Explorer
- Логи установки/обновления Windows (`Panther`)
- Файлы `.log` в `C:\Windows\Logs`
- Корзина
- Папка Prefetch (опционально, по умолчанию выключено)

Встроенная защита: приложение никогда не тронет системные папки верхнего
уровня (`C:\`, `C:\Windows`, `C:\Program Files`, `C:\Users`,
`C:\ProgramData` и т.д.), даже если переменная окружения не задана или
указывает на что-то неожиданное.

## Требования

- Windows 10/11
- Python 3.8+ (только для запуска из исходников — сторонние пакеты не нужны)
- Права администратора (запрашиваются автоматически через UAC)

## Запуск из исходников

```bash
python ritm.py
```

## Сборка в отдельный .exe

```bash
pip install pyinstaller
pyinstaller --onefile --noconsole --icon=app.ico ritm.py
```

Готовый файл появится в папке `dist/`.

## Лог ошибок

Если что-то не удалось удалить (например, файл был занят), приложение
записывает подробности в:

```
%LocalAppData%\Ritm\ritm_errors.log
```

Файл перезаписывается при каждом запуске, поэтому в нём всегда данные
последней очистки.

## ⚠️ Важно

Приложение **безвозвратно удаляет файлы** (для большинства целей — минуя
корзину, а саму корзину при этом ещё и очищает). Убедитесь, что понимаете,
что будет удалено, прежде чем нажимать кнопку. Используйте на свой риск —
автор не несёт ответственности за потерю данных.
